# quant-factor-research
A-share factor research & report replication project.

## Introduction
This project learns factor investment from *Factor Investment: Methods and Practice* by Chuan Shi, Yangyi Liu and Xiangbin Lian.
I use Python to implement A-share factor backtest and replicate sell-side research ideas.

## Libraries
Pandas, NumPy, Matplotlib, Seaborn, Akshare, Jupyter Notebook

## Folder Structure
- README.md: Project description
- notebooks/: Jupyter research & backtest notebooks
- src/: Factor calculation source code
- data: A-share raw data (ignored by git)
- docs: Notes for books and research reports
